# Security Policy

## Сообщение об уязвимости

Если вы нашли уязвимость, не создавайте публичный Issue.
Используйте GitHub Private Vulnerability Reporting
(вкладка Security → Report a vulnerability).

Ответ в течение нескольких дней, исправление по мере возможности.

## Область

Проект учебный. Версия main считается поддерживаемой.
